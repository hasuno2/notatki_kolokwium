============================================================
1. TRÓJKĄT Z BOKÓW a, b, c
============================================================
Warunek istnienia trójkąta:

a < b + c
b < a + c
c < a + b

Praktycznie:
naj = największy z (a, b, c)
reszta = suma dwóch pozostałych

Trójkąt istnieje, gdy:
naj < reszta
============================================================


============================================================
2. TRZY PUNKTY WSPÓŁLINIOWE (czy leżą na jednej prostej)
============================================================
Punkty:
A(x1, y1), B(x2, y2), C(x3, y3)

Liczymy:
dx1 = x2 - x1
dy1 = y2 - y1
dx2 = x3 - x1
dy2 = y3 - y1

Podwójne pole trójkąta:
T = dx1 * dy2 - dx2 * dy1

Interpretacja:
T = 0  -> punkty na jednej prostej
T ≠ 0  -> tworzą trójkąt

Uwzględnienie dokładności:
|T| < epsilon  -> współliniowe
|T| >= epsilon -> nie współliniowe
============================================================


============================================================
3. TOŻSAMOŚĆ:
    (x² − 1) / (x − 1) = x + 1
============================================================
Prawdziwa dla każdego x ≠ 1:

(x² − 1) = (x − 1)(x + 1)

Numerycznie sprawdzamy:
L = (x² − 1) / (x − 1)
R = x + 1

Porównanie:
|L − R| < epsilon  -> równe numerycznie
x = 1              -> dzielenie przez zero (osobny przypadek)
============================================================


============================================================
4. RÓWNOLEGŁE PROSTE (4 punkty)
============================================================
Dane:
pierwsza prosta przez: (x1, y1), (x2, y2)
druga prosta przez:    (x3, y3), (x4, y4)

Przypadek A – obie proste pionowe:
x1 = x2  oraz  x3 = x4  -> równoległe

Przypadek B – jedna pionowa:
(x1 = x2) XOR (x3 = x4) -> NIE równoległe

Przypadek C – liczymy współczynniki kierunkowe:
a1 = (y1 - y2)/(x1 - x2)
a2 = (y3 - y4)/(x3 - x4)

Warunek równoległości:
|a1 - a2| < epsilon
============================================================


============================================================
5. KIEDY PUNKTY TWORZĄ TRÓJKĄT?
============================================================
Punkty A, B, C tworzą trójkąt wtedy, gdy NIE są współliniowe.

Używamy tego samego T co wcześniej:

T = (x2 - x1)
